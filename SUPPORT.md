# Support

## Where to Ask

- Use GitHub issues for bugs, confusing diagnostics, missing docs, and feature
  requests.
- Use the lint proposal template for new lint ideas.
- Use the real-world example template when a crate layout should become a
  compatibility fixture or documentation recipe.

## Before Filing

Please include:

- `feature-manifest` version from `cargo fm --version`,
- Rust version from `rustc --version`,
- the command you ran,
- the relevant `Cargo.toml` feature and metadata sections,
- whether the issue happens locally, in CI, or during publish checks.

## Maintainer Expectations

Clear reproduction cases and minimal manifests make issues faster to diagnose.
